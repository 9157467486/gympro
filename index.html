💪 GymPro Setup

One-time Firebase configuration

Step 1 — Create Firebase Project
Go to console.firebase.google.com → Add project → name it "GymPro" → Disable Google Analytics (optional) → Create.
Step 2 — Enable Authentication
In your project → Build → Authentication → Get Started → Sign-in method → Enable Email/Password → Save.
Step 3 — Create Firestore Database
Build → Firestore Database → Create database → Start in test mode → Choose region (asia-south1 for India) → Enable.
Step 4 — Get Config Keys
Project Settings (⚙️) → General → Your apps → Web app (</>) → Register app → Copy the firebaseConfig object below and paste it here:
Step 5 — Create Admin Account

This only runs once. After setup, login with your email.

GymPro Owner Setup Guide
========================

Open App
--------
Use the Vercel link shared by the developer.

First Time Firebase Setup
-------------------------
1. Open https://console.firebase.google.com
2. Create a project named GymPro.
3. Enable Authentication -> Email/Password.
4. Enable Firestore Database.
5. Copy the Firebase web app config.
6. Open GymPro and paste that config on the setup screen.
7. Create the owner/admin email and password.

Daily Login
-----------
1. Open the GymPro link.
2. Login with owner/admin email and password.
3. Use Home button anytime to return to Dashboard.
4. Use Back button to return to the previous page.

Add Member
----------
1. Go to Add Member.
2. Fill name, phone, package, join date, and payment.
3. Save.
4. GymPro creates a K40 device ID like M1001.

Renew Expired Member
--------------------
1. Go to Dashboard.
2. Click Expired Members.
3. Click Renew Membership.
4. Select package, amount, payment mode, and save.
5. Receipt opens. Print or send WhatsApp.

Add Staff Timing Rule
---------------------
1. Go to Staff & Salary.
2. Add/Edit staff.
3. Set Morning Start, Morning Half After, Morning End.
4. Set Evening Start, Evening Half After, Evening End.
5. Example:
   Morning Start: 05:30
   Morning Half After: 06:00
   Morning End: 10:00
   Evening Start: 17:00
   Evening Half After: 17:30
   Evening End: 22:00

Staff Attendance Rule
---------------------
Punch before or at Half After = Full shift.
Punch after Half After = Half shift.
Missing one shift = Half Day.
Missing both shifts = Absent.
Each staff can have different timings.

K40 Pro Enrollment
------------------
1. Add member/staff in GymPro.
2. Go to Biometric -> Enrollment.
3. Search the person.
4. Copy the Device User ID.
5. On the ZKTeco K40 Pro, enroll fingerprint using the same ID.
6. In GymPro, click Mark as Biometric Enrolled.

K40 Pro Attendance Sync
-----------------------
1. Go to Biometric -> Sync Logs.
2. Import/sync K40 punch logs.
3. GymPro saves raw logs first.
4. GymPro processes attendance automatically.
5. Check Unmatched Logs if any punch ID is not linked to a member/staff.

Important
---------
Do not enroll fingerprint in browser.
Fingerprint enrollment and matching happen only on the K40 Pro device.
GymPro only handles IDs, attendance, salary, expiry, receipts, reports, and WhatsApp.

💪 GymPro Setup

One-time Firebase configuration

Step 1 — Create Firebase Project
Go to console.firebase.google.com → Add project → name "GymPro" → Create.
Step 2 — Enable Authentication
Build → Authentication → Get Started → Sign-in method → Enable Email/Password → Save.
Step 3 — Create Firestore Database
Build → Firestore Database → Create database → Start in test mode → Enable.
Step 4 — Get Config Keys
Project Settings (⚙️) → General → Your apps → Web app → Register → Copy the firebaseConfig JSON below:
Step 5 — Create Admin Account

This runs only once. After setup, login with your email/password.
